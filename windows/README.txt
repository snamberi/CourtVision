COURTVISION - Windows edition
=============================

HOW TO RUN
  1. Right-click the zip and choose "Extract All..." (do not run it from inside the zip).
  2. Open the extracted CourtVision folder and double-click  "Start CourtVision.bat".
  3. CourtVision opens in its own window (Microsoft Edge or Chrome) or in your default browser.

  A black console window stays open while the game runs. Close it to stop CourtVision.

NOTHING TO INSTALL
  Everything used ships with Windows 10 and 11 (PowerShell and a web browser). No admin rights needed.

IF WINDOWS SHOWS "Windows protected your PC"
  This is SmartScreen being cautious about any downloaded script that is not code-signed.
  Click "More info", then "Run anyway".

YOUR SAVED LEAGUES
  Leagues are saved automatically inside your browser, tied to the address http://localhost:47820.
  - Always start the game with "Start CourtVision.bat" so the address stays the same.
  - Deleting this folder does NOT delete your saves, and clearing your browser's site data DOES.
  - For a backup, use the Export button in the app (or press Ctrl+S) to save a universe file.

TROUBLESHOOTING
  - "Port is busy": another program is using port 47820. Close it and start again.
  - Nothing opens: open your browser and go to http://localhost:47820
  - Blank page: make sure you extracted the whole zip and the "app" folder sits next to this file.
